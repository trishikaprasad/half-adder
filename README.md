# Half Adder using Verilog HDL

## 📌 Overview

This project implements a **Half Adder** using **Verilog HDL** and is simulated using **Xilinx Vivado**.

A Half Adder is a combinational digital circuit that adds two 1-bit binary numbers and produces two outputs:

- **Sum**
- **Carry**

## 🔧 Tools Used

- Verilog HDL
- Xilinx Vivado
- Behavioral Simulation

## ⚙️ Logic

The Half Adder uses:

- XOR gate for **Sum**
- AND gate for **Carry**

### Boolean Expressions

```text
Sum = A ⊕ B
Carry = A & B
